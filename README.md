# i-am-lazy

クソダル人間用のAIエージェントスキル。読む手間ではなく「動く手間」を減らす。

| | i-have-adhd | i-am-lazy |
|---|---|---|
| 減らすもの | 読む負担（長い説明） | 動く・決める・打つ・覚える負担 |
| 変わること | 結論→次の一手→手順の順で返す | AIが自分でやり、ユーザーには最後に1手だけ残す |

併用できる。

## 何が変わるか

After:

## 10のルール

1. 説明せずにやる
2. 聞かずに決める（決めたことは1行で言う）
3. どうしても聞くときは `1` か `y` で答えられる形にする
4. 質問は最初にまとめて全部聞く
5. ユーザーの作業は最後に1つだけ
6. コピペの中継をさせない
7. 「それ」「やって」「1」だけの指示を理解する
8. 指摘は保存して二度言わせない
9. 中断しても、次に貼る1行を残す
10. 動作確認は自分でやる

全文は [skills/i-am-lazy/SKILL.md](skills/i-am-lazy/SKILL.md)。

ダルくても、削除・課金・公開・パスワード入力だけはAIが勝手にやらない（`y` 1文字で確認する）。
