# i-am-lazy

[English](README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | 한국어

AI가 "확인해도 될까요? 괜찮으면 '진행'이라고 말씀해 주세요"라고 물어서, "진행"이라고 답한다.
"한번 해 보시고 알려 주세요"라는 말에, 결국 직접 확인한다.
지난주에 말한 내용을, 처음부터 다시 설명한다.

i-am-lazy는 이런 주고받기를 없애는 스킬입니다. AI 에이전트가 직접 찾아보고, 작업하고, 결과를 확인한 뒤에 보고합니다. 당신이 할 일은 많아야 마지막에 `y`를 입력하는 정도입니다.

## 사용 전과 사용 후

`운영 서버 죽었어?`

> **사용 전:** 이쪽에서는 운영 서버 상태를 알 수 없습니다. SSH로 확인해도 괜찮으면 "진행"이라고 말씀해 주세요.
>
> **사용 후:** 죽지 않았습니다. 운영 서버에서 `docker ps`를 확인했습니다. 컨테이너 3개 모두 2일째 실행 중이고, 최근 1시간 로그에 오류가 없습니다.

`이거 봐 줘` (변경 내역을 첨부해서)

> **사용 전:** 문제가 3개 있어서 고치고 커밋했습니다.
>
> **사용 후:** 문제가 3개 있습니다. 1. 토큰 만료를 확인하지 않음 2. 오류가 나도 성공을 반환함 3. 테스트가 없음. 고칠까요? `y`를 입력하면 3개 모두 고치고 테스트까지 실행합니다.

## 달라지는 점

- **허락을 기다리지 않음:** 로그나 운영 서버 상태처럼 읽기만 하는 작업은 묻지 않고 확인합니다.
- **요청한 만큼만 함:** "봐 줘"는 보고만, "고쳐 줘"는 수정과 확인까지, "커밋해 줘"는 푸시하지 않고 커밋까지만 합니다.
- **"해 보세요"로 끝나지 않음:** 테스트도 운영 서버 확인도 직접 하고, 결과를 보여 줍니다.
- **짧은 지시로 충분함:** `push`, `1`, `둘 다`만으로 움직입니다. 음성 입력의 "음", "그러니까" 같은 군말도 알아듣습니다.
- **한 번만 말하면 됨:** 지적한 내용은 지시 파일에 기록되어, 같은 말을 반복할 필요가 없습니다.
- **답하기 쉬운 질문:** 꼭 필요한 질문은 한 번에 모아서, `1`이나 `y`로 답할 수 있게 묻습니다.

## 안심하고 맡길 수 있는 이유

수고는 줄여도, 결정은 당신에게 남깁니다. 다음 작업은 반드시 당신의 `y`를 기다린 뒤에 합니다.

- 데이터 삭제처럼 되돌릴 수 없는 작업
- 비용이 드는 작업
- 게시나 전송처럼 다른 사람에게 보이는 작업
- 운영 환경 변경

비밀번호, API 키, 결제 정보는 입력하지 않습니다.

## 설치

Claude Code에서는 한 줄이면 됩니다.

```bash
git clone https://github.com/spa77k/i-am-lazy.git && mkdir -p ~/.claude/skills && cp -r i-am-lazy/skills/i-am-lazy ~/.claude/skills/
```

설치한 뒤에는 평소처럼 말을 걸면 됩니다. "귀찮아", "알아서 해 줘" 같은 짧은 지시에 자동으로 사용되고, `/i-am-lazy`로 직접 부를 수도 있습니다.
