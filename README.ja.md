# i-am-lazy

[English](README.md) | 日本語

AIエージェントが自分で調べ、作業し、結果を確かめるようにするスキルです。あなたに残す作業は、最後に1つまでにします。

## インストール

Claude Code の場合：

```bash
git clone https://github.com/spa77k/i-am-lazy.git && mkdir -p ~/.claude/skills && cp -r i-am-lazy/skills/i-am-lazy ~/.claude/skills/
```

## 変わること

- ログや本番の状態の確認など、読むだけの作業は許可を求めずに行います。
- 依頼の言葉どおりの範囲で止まります。「見て」なら報告だけ、「直して」なら修正と確認まで、「コミットして」ならpushの手前までです。
- テストや本番の確認を自分で行い、結果を示します。「試してください」で終わりません。
- `push`、`1`、`両方` のような短い指示や、音声入力の言いよどみも読み取ります。
- 一度指摘したことは指示ファイルに記録し、同じ指摘を繰り返させません。
- 質問は1回にまとめ、`1` や `y` で答えられる形にします。

## 例

`本番落ちてない？` と聞いた場合：

使う前：

> 本番の状態はこちらからは分かりません。SSHで確認してよければ「やって」と言ってください。

使った後：

> 落ちていません。本番で `docker ps` を確認しました。3つのコンテナはすべて2日間稼働しており、直近1時間のログにエラーはありません。

## 自動では行わない操作

次の操作は、必ずあなたの承認（`y` の1文字）を得てから行います。

- データの削除など、取り消せない操作
- 支払いが発生する操作
- 公開や送信など、他の人に見える操作
- 本番環境の変更

パスワード、APIキー、支払い情報の入力は行いません。
